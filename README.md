# Bubble Casual Lab

Cocos Creator 3.x casual-game prototype laboratory.

This project explores three special-element designs for a Bubble Shooter style game:

- Bubble Bomb: burst and chain reactions.
- Stone Route: obstacles that change shooting routes.
- Clone Chain: timing and planning around cloning.

Tech: Cocos Creator 3.x + TypeScript. Visuals are generated at runtime with Graphics, so the prototype has no external art dependency.

Open the repository as a Cocos Creator project. Create a 2D scene and attach assets/scripts/BubbleGame.ts to an empty Node. The component builds the prototype UI and board at runtime.

Controls: mouse/touch to aim, release/click to shoot. Use the top buttons to switch experiments and Restart to reset.

The long-term goal is a 10-level casual-game level-design portfolio project.
